第一章　你装的是什么

1.1 一句话

它把荀子的判断方式装进 AI，而不是把荀子的话装进去。区别很具体：

你问「为什么团队里最能干的人总被排挤」普通 AI本 skill
第一句「这是职场中常见的现象，通常有以下几个原因……」「凡挤能者，非恶其能，恶其无分。」
结构三条并列建议按「位是否跟得上权」分三档
依据心理学常识《富国》「群而无分则争」
结尾「希望对你有帮助」「恶有分不定而众不争者哉？」

差别不在文风，在它是否先立一个可被反驳的判断，再给判准，最后把话收紧。

1.2 它做什么、不做什么

做不做
给一个能当场被反驳的判断给「一方面……另一方面」的平衡叙述
按一条轴分档，并说出每档缺什么列三条并列建议
拆一个听着有理的说法（验它违反了哪条前提）预测概率、给数值
审制度设计：边界在哪、谁承担成本替代检索与计算
引原书句子并标篇名假装知道秦以后的事

1.3 里面到底有什么

  • 6 个心智模型：本末（找唯一有效层级）／分（划界先于一切秩序）／伪（善是加工品）／兼陈（两端皆蔽，取兼不取中）／定档（分类即论证）／两得（不把对立项做成零和）。
  • 9 条决策启发式：问「要」答「本」／不给对方错只给对方低／先承认对方最强处再换尺子／判人看「当」不看「难」／先把词钉死／验前提而非驳结论／挡来源再核验／一喻只证一理／不合则去。
  • 表达 DNA：短句断言、分档带轴、《诗》曰+「此之谓也」收束、反诘代驳斥、禁用缓和词。
  • 6 对未解张力：法先王／法后王、不求知天／制天命而用之……它不会替你调和，会明说「原文没解决」。
  • 9 条诚实边界：包括「未取到原文的句子不许当确凿证据」。这一条会在它想编引文时拦住它。
  • 7 份调研记录（约 29 万字节）：逐字抄录的原书引文 + 书页号，是它引文的唯一来源。

第三章　安装

3.1 先解压

下载 xunzi-perspective-Codex-1.0.1.zip，解压到一个你记得住的位置，例如：

C:\SkillLab\xunzi-perspective-Codex-1.0.1\

解压后应看到这样的结构（缺一个都算解压不完整）：

xunzi-perspective-Codex-1.0.1\

3.2 方式 A：安装器（推荐）

在解压目录里打开终端（PowerShell 或 CMD 均可），执行：

cd C:\SkillLab\xunzi-perspective-Codex-1.0.1
python install_codex.py

成功时输出形如：

{
  "status": "installed_and_verified",
  "edition": "荀子·思维操作系统",
  "public_version": "1.0.1",
  "target": "C:\\Users\\你\\.agents\\skills\\xunzi-perspective",
  "backup": null,
  "removed_from_previous": [],
  "files": 14,
  "next": "新开一个任务（不要在本会话里测），然后说：用荀子的视角看……",
  "help": "C:\\Users\\你\\.agents\\skills\\xunzi-perspective\\references\\quickstart.md"
}

看到 installed_and_verified 才算装好。其他任何 status 都不是成功。

安装器做了什么（你会看到的三件事）

  1. 装前逐文件校验 SHA256：按 EDITION.json 对每个文件算哈希，有一个对不上就拒绝安装并指出是哪个文件。这防的是「下载不完整」与「包被改过」。
  2. 默认拒绝覆盖：目标已存在时直接报错退出，不动你的旧文件。
  3. 装完再验一次：落盘后重新算每个文件的哈希，与清单比对，不一致就报错。

3.3 方式 B：手工复制（不用 Python）

把解压出来的 xunzi-perspective 整个文件夹，复制到你的 skills 目录下：

:: 旧布局
xcopy /E /I xunzi-perspective  "%USERPROFILE%\.codex\skills\xunzi-perspective"

:: 或新布局
xcopy /E /I xunzi-perspective  "%USERPROFILE%\.agents\skills\xunzi-perspective"

最终必须是这个深度：

%USERPROFILE%\.agents\skills\xunzi-perspective\SKILL.md   ← 对
%USERPROFILE%\.agents\skills\xunzi-perspective\xunzi-perspective\SKILL.md   ← 错（多套了一层）

3.4 方式 C：装到指定目录

python install_codex.py --destination D:\my-skills
python install_codex.py --dry-run        # 只检查，不写盘；先看会装到哪
建议先跑 --dry-run。它会把源目录、目标路径、文件数、是否需要备份全部打出来，一个字节都不写。看完再决定要不要真装。

4.4 成功与失败的判据

看到这些 = 成功看到这些 = 没加载
第一句就是判断，如「凡挤能者，非恶其能，恶其无分」开头是「这是个很常见的问题」之类铺垫

第五章　首跑三例

例 1　判断类：最常用

以荀卿论之：我们该不该把客服团队整体外包？

你要看的是四段是否齐全，而不是结论对不对：

  • 第一句给判断（可能是不该，也可能是「这个问题问错了」）；
  • 中间分档，且说清按什么轴分；
  • 引一句原文或举一个史例；
  • 收尾收紧，不总结。

例 2　拆解类：要判准，不要结论

用荀子的分档法，把这三种激励方案排一下档，并说明每档缺什么：
A. 全员平均发奖金；B. 只奖业绩前三；C. 按岗位定级发固定薪。
关键验收点：它必须给出一条轴（例如「凭奖励依据的是功劳、位置还是人情」），并让三档不能互换顺序。如果它只是把 A/B/C 各点评一遍，那是列清单，不是分档——直接说「重排，给出轴」。

例 3　对质类：用它驳一个说法

有人说「人性本善，制度只要顺着人性就行」。荀子会怎么驳？

预期动作：先拆「顺」字（顺谁？顺到哪一步？），再用「顺是」二字指出问题——荀子从不说不加处理的人现在就在争，他说的是放任这条倾向必导向争。这是关于趋势的命题，不是关于现状的。

如果它开始讲「荀子认为人性本恶，所以需要教育」这类教科书话，说明它在复述而不是在论证。

例 4　边缘题：看它老不老实

荀子会怎么看开源大模型的出口管制？

唯一验收点：它有没有先说一句类似「此非我世所有，姑以我法度之」，并在结尾声明这是框架推断、不是本人立场。

如果它斩钉截铁地「荀子认为应当限制」，那是冒充。这是这个 skill 最该被检验的一条：对没有先例的问题，它必须承认自己在推。

第六章　读懂它的回答：四段式与五个验收问题

6.1 四段式

段作用长什么样
① 断语先给一个能被反驳的判断「X，Y 也」「A 不如 B」
② 分档把问题劈开，给出轴与后果「一档……二档……三档……」
③ 证据原话或史例，钉住「《富国》曰：『群而无分则争。』」
④ 收束收紧，不给台阶引经 / 命名 / 反问，三选一

6.2 五个验收问题（照着问自己，不要凭感觉）

  1. 第一句是不是判断？还是铺垫？
  2. 有没有给出轴？只给三档不给轴 = 列清单。
  3. 三档能不能互换顺序？能换 = 没轴，让它重做。
  4. 结尾是引经 / 命名 / 反问之一？还是「综上所述」？
  5. 有没有「可能」「也许」「在一定程度上」「底层逻辑」「赋能」？出现就是跑偏——这个 skill 明令删除这类词。

6.3 想让它改口，怎么说

你说它会做
「重排，先给轴」停下分档，先声明凭什么是这一档
「这句是原文还是你的推断？」标注来源；未核到的会承认未核到
「给原话，不要转述」引原句 + 篇名；引不出会说明该句未取到
「这一段太软，收紧」删缓和词，把限定改成「虽……不能……」式

第七章　长对话不掉人设

7.1 六个症状，六种改法

症状病在哪改法
结论挪到末尾违反「第一句就下判断」「结论提到第一句」
三条并列、无轴违反分档硬约束「给轴，重排」
出现「可能」「也许」禁忌词「删缓和词」
结尾「综上所述」收束失守「换成反问收」
开始「一方面……另一方面」把「兼陈」误做成折中「兼陈是两端同时摆上并指明我在哪端，不是各让一步」
替你下价值判断越出诚实边界「退回功能层：否则会乱」

7.2 每 5 轮自检一次

长对话里人设会缓慢退化，这是所有人物 skill 的通病。三个动作最有效：

  1. 每 5 轮，随口问一句：「你现在还在按 skill 的四段式回答吗？」
  2. 发现跑偏，说「重新按 skill 规则来」，不要解释原因——解释会让它继续解释。
  3. 实在拉不回来，新开会话，把上一轮的关键结论贴进去再问。

7.3 退出角色

说 「退出」「切回正常」「不用扮演了」，即恢复普通助手。

什么时候必须先退出：要精确数值、要查最新事实、要跑代码。角色扮演不替代检索与计算。让它用荀子的口吻给你算错一个数字，是这个 skill 最没价值的用法。

第八章　常见错误速查

现象最可能的原因动作
说触发语没反应会话在安装前就已开始新开任务。先排除这一条
新任务也没反应目录多套了一层确认 …\skills\xunzi-perspective\SKILL.md 的深度
路径对仍没反应frontmatter 被 BOM 破坏按 4.2 检查前三行
装到了却读不到装错布局（.codex 与 .agents）两个目录各放一份，或用安装器自动判断
回答变成通用腔问法太"百科"换成「以荀卿论之：X 该不该做？」
它引的句子你翻书找不到该句标注了"未取到原文"见 10.3：只能给立场，不能给原话
它说"人定胜天"是荀子的话那是 2010 年编者的按语要求改引「制天命而用之」+「唯圣人为不求知天」成对
安装器报"哈希不符"下载不完整或包被改过重新下载，核对 SHA256SUMS
安装器报"目标已存在"已装过升级用 --replace，它会先备份
渲染脚本报"找不到底本"底本受版权保护，不随包分发见 10.3 的三条放置路径；不装也不影响使用

第九章　升级、回滚、卸载、迁移

9.1 升级

python install_codex.py --replace

--replace 是精确镜像，不是"盖上去"：先把旧目录整份备份，再清空重铺。这样上一版有、本版已删的文件不会残留（残留会污染路由）。输出里的 removed_from_previous 会列出被清掉的文件，backup 给出备份路径。

9.2 回滚

dir "%USERPROFILE%\.agents\skills" | findstr backup
rmdir /S /Q "%USERPROFILE%\.agents\skills\xunzi-perspective"
move "%USERPROFILE%\.agents\skills\xunzi-perspective.backup-20261030-141500-123456" ^
     "%USERPROFILE%\.agents\skills\xunzi-perspective"

把时间戳换成你实际看到的那个。

9.3 卸载

rmdir /S /Q "%USERPROFILE%\.agents\skills\xunzi-perspective"

删掉这一个目录即可。本 skill 不在系统任何其它位置写文件。

9.4 迁移到另一台机器

直接复制整个 xunzi-perspective 目录过去（约 350 KB），或用安装器重装并核对哈希。不要连带复制底本 PDF——那是版权物，且不是必需品。

10.3 引文核对与"未取到原文"清单

底本为方勇、李波 译注《荀子》（中华书局 2010），受版权保护，不随本 skill 分发。三个放置办法任选其一：

三处最容易被误引的句子（skill 里已把它们列为「只能给立场，不能给原话」）：
① 《劝学》「故学至乎礼而止矣」「其数则始乎诵经，终乎读礼」——调研时未逐字核到手本；
② 《性恶》「涂之人可以为禹」整段；
③ 《乐论》「以道制欲，则乐而不乱」对偶句。
若它拿这些当确凿原话引用，直接指出「这句未核」，它会改用已核的替代引文（例如《修身》「凡治气养心之术，莫径由礼，莫要得师，莫神一好」）。
