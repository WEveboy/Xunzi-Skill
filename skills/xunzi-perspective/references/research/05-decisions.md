# 生平关键决策

> 处理原则：**只写有史料支撑的行动**。凡属推论，明标"推论"；凡属后世想象（如"荀子游燕王哙"之类），进"存疑"栏而不进正文。
> 荀子生平的文献基础极薄：核心只有《史记》本传约二百字、刘向《孙卿书录》约四百字，加上《荀子》书内的自述性段落。SEP 直接说《史记》传记"被认为存在严重失真"（引 Kern 2015），现代复原"都只能是推测性的"。

## 一、可考的生平骨架

### 1. 史料层级

| 层级 | 文献 | 性质 | 可信度 |
|---|---|---|---|
| A | 《荀子》书内涉及行事诸篇（《议兵》《强国》《儒效》《富国》等） | 当事人/学派内部记录，但经刘向编校、可能有窜入 | 一手，但需逐篇评估 |
| A | 《史记·孟子荀卿列传》 | 汉初人作，距荀子约二百年 | 一手（最早传记），但有错简与断句问题 |
| A | 刘向《孙卿书录》（前 26 前后） | 校书叙录，兼作传记 | 一手，但含明显讹误（"孙膑议兵"） |
| B | 《战国策·楚策四》《韩诗外传》卷四 | 平行记载春申君聘荀子事 | 一手（旁证），与刘向互校 |
| B | 《盐铁论·论儒》 | 西汉中期，记湣王时诸儒散去、"孙卿适楚" | 一手（旁证），但为论辩语境 |
| C | 《风俗通义·穷通》（应劭，东汉末） | "年十五始来游学"的唯一出处 | 一手，但晚出，且孤证 |
| C | 《韩非子·难三》 | "燕王哙贤子之而非孙卿" | 一手，但一句话，且学派立场敌对 |
| D | 《颜氏家训·勉学》 | "荀卿五十始来游学" | 二手（引《史记》古本） |

### 2. 骨架（事件序，非严格编年）

1. 赵人，名况，时人尊称"荀卿"（汉避宣帝刘询讳，或作"孙卿"）。
2. 某年（争议：十五或五十）**始来游学于齐**，入稷下。
3. 齐襄王时"**最为老师**"，"**三为祭酒**"。
4. 齐人**谗**之，**适楚**。
5. 春申君（黄歇）用为**兰陵令**（第一次）。
6. 有人以"百里地"为患说春申君，春申君**谢**（辞退）荀子；荀子**去，之赵**。
7. 又有客说春申君"贤者所在，君尊国安"，春申君**使人聘**；荀子**遗书、作歌赋**讥刺楚国；春申君**固谢**，荀子**复为兰陵令**（第二次）。
8. 其间**应聘于诸侯，见秦昭王**（及应侯范雎）；**至赵，议兵于赵孝成王前**。
9. 前 238 年**春申君死**（李园刺杀），荀子**废**，**因家兰陵**。
10. 家居**著书数万言而卒**，**葬兰陵**。

出处：《史记·孟子荀卿列传》"荀卿，赵人。年五十始来游学于齐……齐尚修列大夫之缺，而荀卿三为祭酒焉。齐人或谗荀卿，荀卿乃适楚，而春申君以为兰陵令。春申君死而荀卿废，因家兰陵。李斯尝为弟子，已而相秦。……序列著数万言而卒。因葬兰陵。"（https://ctext.org/shiji/meng-zi-xun-qing-lie-zhuan/zh ，一手史料）

刘向补充了**第 6、7 两步**，这是《史记》没有的关键情节：
> "人或谓春申君曰：'汤以七十里，文王以百里，孙卿贤者也，今与之百里地，楚其危乎？'春申君谢之。孙卿去之赵。后客或谓春申君曰：'伊尹去夏入殷，殷王而夏亡；管仲去鲁入齐，鲁弱而齐强。故贤者所在，君尊国安。今孙卿天下贤人，所去之国，其不安乎？'春申君使人聘孙卿。孙卿遗春申君书，刺楚国，因为歌赋以遗春申君。春申君恨，复固谢孙卿，孙卿乃行，复为兰陵令。"

出处：《孙卿书录》，《全汉文》卷三七，https://zh.wikisource.org/zh-hans/全漢文/卷三十七 （一手史料）。清儒校注指出《楚策四》《韩诗外传》卷四有平行记载（"聘"作"请"）——见《荀子集解》校记，转引自中国国家图书馆《中国古籍保护网》文，https://www.nlc.cn//pcab/zx/xw/20260605_2653378.shtml 。

**这个"两度任免"的细节极其重要**：它说明荀子不是被礼聘后安坐的国师，而是经历了一次**被辞退—离开—被追回—写讽刺作品—再被请回**的完整折辱循环。他第二次上任时，是带着一封骂楚国的话和一篇赋回去的。

## 二、逐个决策的处境分析

每节四栏：**他做了什么 / 处境约束 / 史料依据 / 后世评价**。

### D1　赴齐游学稷下

| 项 | 内容 |
|---|---|
| **做了什么** | 离开赵国，入齐都临淄稷下学宫。 |
| **处境约束** | 战国末年，稷下是天下唯一的"跨国学术市场"：齐以"列大夫"爵禄养士，"不治而议论"，学者可自由来去。对赵人荀况而言，这里是唯一能同时接触到儒、道、法、名、阴阳各家前沿的地方。刘向说他"善为《诗》《礼》《易》《春秋》"——他带着经典训练来的。 |
| **年龄争议** | 见下"三、史料分歧 1"。此事不能说定，本文件不给单一结论。 |
| **史料依据** | 《史记》本传；刘向《书录》；《风俗通义·穷通》。 |
| **后世评价** | 钱穆认为"游学"是"特来从学于稷下诸先生而不名一师者"，即**学生身份**，故必是少年（《先秦诸子系年·荀卿考》）。胡适则认为"始"字含"来迟了"之意，若十五岁"决不必用'始'字"，故主张五十。**两人读同一个字，读出相反意思**——这是文献不足的典型样本。 |

### D2　留齐为"老师"、三为祭酒

| 项 | 内容 |
|---|---|
| **做了什么** | 齐襄王时（前 283 年后），田骈一辈已死，荀子成为稷下资历最深者，"最为老师"；齐国"尚修列大夫之缺"，他"三为祭酒"。祭酒即学宫之长/首席，非行政官职，而是学术共同体的推举性尊位。 |
| **处境约束** | 前 284 年五国伐齐、燕将乐毅破临淄，稷下瓦解，湣王死。襄王复国后重建稷下，但人才凋零（"田骈之属皆已死"）。荀子此时是**唯一剩下的符号性人物**——他的"老师"地位一半来自学问，一半来自稀缺。 |
| **史料依据** | 《史记》："田骈之属皆已死齐襄王时，而荀卿最为老师。齐尚修列大夫之缺，而荀卿三为祭酒焉。"（一手史料）刘向同。 |
| **后世评价** | 一说"三为祭酒"是**三次担任**，一说"三"为虚数表频次（"屡次"）。无定论。此职位不含决策权，所以"荀子在齐国有多大实权"这个问题本身可能问错了——他更像**学术领袖而非政治顾问**。 |

### D3　说齐相（劝阻齐国的多线树敌）

| 项 | 内容 |
|---|---|
| **做了什么** | 向齐国执政者进言，指出齐国地缘上的致命处境：前有巨楚，后有燕，右有劲魏，一旦"一国作谋，三国必起而乘我"，则"齐必断而为四"。 |
| **原文** | "今巨楚县吾前，大燕鳅吾后，劲魏钩吾右，西壤之不绝若绳，楚人则乃有襄贲、开阳以临吾左。是一国作谋，则三国必起而乘我。如是，则齐必断而为四，三国若假城耳。"（《荀子·强国》） |
| **处境约束** | 齐湣王晚期，齐国灭宋（前 286）、南割楚淮北、西侵三晋，正值扩张顶点，也是树敌顶点。此时进"收敛"之言，在政治上必然不受欢迎。 |
| **史料依据** | 《荀子·强国》篇首"荀卿子说齐相曰"（一手史料）。汪中《荀卿子通论》考定此"齐相"为薛公田文，事在湣王世，并评："其后五国伐齐，燕入临菑，楚、魏共取淮北，卒如荀卿言。荀子之为齐，与乐毅之为燕谋伐齐，所见正同，岂可谓儒者无益于人国乎！"（转引自《中国古籍保护网》引《荀子集解》校记，https://www.nlc.cn//pcab/zx/xw/20260605_2653378.shtml ） |
| **后世评价** | 汪中的评价是"儒者有益于人国"的证明——即：荀子不是空谈家，他的战略判断被前 284 年的事变验证了。但也有一层反讽：**预言正确而未被采纳，恰恰说明他的位置没有影响力**。这是一个"说对了但没用"的典型决策困境。 |

### D4　遭谗去齐，适楚

| 项 | 内容 |
|---|---|
| **做了什么** | 有人向齐王进谗，荀子离开齐国，前往楚国。 |
| **处境约束** | 稷下学士"不治而议论"，看似自由，实无根脚：**爵禄来自君主，去留系于一人之喜怒**。无封地、无兵、无宗族根基。这是战国游士的结构性脆弱。 |
| **史料依据** | 《史记》"齐人或谗荀卿，荀卿乃适楚"（一手）。《盐铁论·论儒》提供了另一种离开理由：湣王"矜功不休……诸儒谏不从，各分散，慎到、捷子亡去，田骈如薛，而孙卿适楚"——即**因谏不听而集体出走**，非因谗。 |
| **后世评价** | 两说可并存：先谏不听（D3），后被谗（D4），最终出走。不必二选一。但要注意，《盐铁论》是西汉昭帝时盐铁会议的论辩文本，用法带有"儒者见弃"的修辞目的，不宜当纯史实。 |

### D5　受春申君之聘，第一次为兰陵令

| 项 | 内容 |
|---|---|
| **做了什么** | 接受楚国令尹春申君（黄歇）的任命，出任兰陵（今山东兰陵/苍山）令。 |
| **处境约束** | 春申君为战国四公子之一，前 262—前 238 年相楚，正大规模养士、扩张封地，需要"天下贤人"装点与实干。兰陵是楚国东北边的新得之地（灭鲁后所得），既是边邑，也是**文化前沿**——需要一个懂礼、能教化的人去"治"。对荀子而言，这是**唯一一次真正拿到治民之权**。 |
| **史料依据** | 《史记》"春申君以为兰陵令"；刘向同。 |
| **后世评价** | 有学者主张兰陵令**不在襄王之后，而在湣王末年的那次离齐适楚**，其时荀子"年当五十五、六"，理由是"荀卿年八十为兰陵令"于理不通（中国社会科学网《荀子行历述考及补正》，https://www.cssn.cn/zx/zgzx/202210/t20221027_5554859.shtml ）。此为一说，非共识。传统说法（汪中以下多数）仍系于春申君相楚期间。 |
| **注意一个事实** | 荀子治兰陵的实际效果，史料只留下一句间接证据：刘向说"兰陵多善为学，盖以孙卿也。长老至今称之，曰：'兰陵人喜字为卿。'盖以法孙卿也。"——**兰陵人用"卿"字给孩子取字，是模仿荀子**。这是极罕见的一条"治理留下民间痕迹"的记录，比任何政绩数字都实在。（一手史料，刘向《书录》） |

### D6　因"百里地"之谮而辞官去赵

| 项 | 内容 |
|---|---|
| **做了什么** | 有人对春申君说：商汤以七十里、文王以百里而王天下，你把百里之地给了荀卿这样的贤人，楚国危险了。春申君于是"谢"（辞退）荀子。荀子**离开楚国，去了赵国**。 |
| **处境约束** | 这是战国养士制度的固有悖论：**养士是为了得贤名，但真贤人掌实权又触发猜忌**。春申君的反应不是判断荀子有无野心，而是回避风险——一种典型的官僚理性。荀子此时无辩白渠道，也无留下来的制度身份。 |
| **史料依据** | 刘向《书录》（一手史料）。 |
| **后世评价** | 刘向的叙述不带评论，但紧接着写下一次"复聘"，形成对照结构：**第一次是谗言驱逐，第二次是利益计算请回**。刘向的判断藏在末段："孙卿卒不用于世，老于兰陵……其言凄怆，甚可痛也。" |
| **这个决策的性质** | 严格说不是他"选择"离开，而是**被辞退**。但把它列入决策清单仍有意义：他没有抗争、没有转投他国复仇、没有像吴起那样以死相搏——**他接受了，然后走了**。这与后来"春申君死而废"时的反应一致：退，著述。两次退出构成一个可辨认的行为模式。 |

### D7　被追回、上书与作赋、再为兰陵令

| 项 | 内容 |
|---|---|
| **做了什么** | 又有客劝春申君："贤者所在，君尊国安"，荀子这样的天下贤人离开楚国，楚国能安宁吗？春申君派人去聘。荀子**先送去一封讥刺楚国的信，并作歌赋（赋）送给春申君**；春申君感到遗憾（"恨"），再次坚决道歉，荀子才动身，**第二次出任兰陵令**。 |
| **处境约束** | 他有了筹码：楚国的邀请证明了他的稀缺性。但他没有军队、没有盟国，唯一的武器是**文字**。 |
| **史料依据** | 刘向《书录》："孙卿遗春申君书，刺楚国，因为歌赋以遗春申君。春申君恨，复固谢孙卿，孙卿乃行，复为兰陵令。"（一手史料） |
| **关键含义** | 这是荀子一生中**唯一一次成功施压**。方式是：不拒绝、不答应，先公开发表讽刺作品，让对方承担舆论成本。这与他"正名"的一贯主张一致——**用命名与言辞重整秩序**，而不是用强力。 |
| **后世评价** | 学界注意这批"赋"与《荀子·赋篇》的关系，但《赋篇》是否即此"歌赋"不能确定（SEP 提到《赋篇》含诗歌与韵谜，Knechtges 1989 有研究）。此事**存疑**，不宜断言。 |

### D8　入秦见秦昭王与应侯

| 项 | 内容 |
|---|---|
| **做了什么** | 应聘入秦，与秦昭王、应侯（范雎）对话。对秦的治理给出"五分肯定 + 一个致命否定"的判断。 |
| **原文要点** | 应侯问"入秦何见"，荀子先列五项"古之民/古之吏/古之士大夫/古之朝"的高度肯定，再说："故四世有胜，非幸也，数也。"转折："虽然，则有其諰矣……县之以王者之功名，则倜倜然其不及远矣。是何也？则其殆无儒邪！故曰：粹而王，驳而霸，无一焉而亡。此亦秦之所短也。"（《荀子·强国》） |
| **处境约束** | 时在秦昭王晚年（一说前 266 年），秦国刚用范雎"远交近攻"、废宣太后与四贵，国势正盛，且正忙于兼并战争。**没有任何理由采纳"用儒"的建议**。 |
| **史料依据** | 《荀子·强国》（一手史料，原文见 https://chinakongzi.org/content/2856_29673.html ）；刘向："孙卿之应聘于诸侯，见秦昭王。昭王方喜战伐，而孙卿以三王之法说之，及秦相应侯皆不能用也。"（一手史料）。余治平考订入秦在昭王四十一年后，见《"荀子入秦"：何以成为一次文化事件？》，《孔子研究》2019 年第 6 期，https://www.rujiazg.com/article/18324 。 |
| **后世评价** | 余治平称之为"中国历史上一个非常重要的文化事件"——儒家圣王之治的理想第一次直面法家治理的现实，而荀子的结论是"秦之所短在无儒"。**从后果看，这是荀子最"正确"的一次判断**（秦十五年而亡），但也是最"无用"的一次：说完就走了，秦没有变。 |
| **一个需要警惕的读法** | 荀子对秦的民风吏治给予了极高评价（"古之民""古之吏"），这与他"性恶"的立场形成张力。有学者（余治平）批评这是"客套话"或"误判"——把被法家驯服的"顺民"误认为"古之民"。这个批评值得保留：**荀子的现场观察可能被自己的"古"框架过滤了**。 |

### D9　议兵于赵孝成王前

| 项 | 内容 |
|---|---|
| **做了什么** | 与临武君在赵孝成王面前辩论用兵之道。临武君主张"上得天时，下得地利，观敌之变动，后之发，先之至"；荀子主张"凡用兵攻战之本在乎壹民"，"善附民者，是乃善用兵者也"。并系统评价各国兵制：齐之技击"不可以遇魏氏之武卒"，魏之武卒"不可以遇秦之锐士"，秦之锐士"不可以当桓文之节制"，桓文之节制"不可以敌汤武之仁义"。结论："故齐之技击，不可以遇魏氏之武卒……有遇之者，若以焦熬投石焉。" |
| **处境约束** | 赵孝成王在位前 265—前 245。此期赵历经长平之战（前 260，赵军四十余万被坑）与邯郸之围（前 258—前 257），国力大损。**在一个刚被打断脊梁的国家讲"仁义之兵"，听众的处境极其残酷**。 |
| **史料依据** | 《荀子·议兵》开篇"临武君与孙卿子议兵于赵孝成王前"（一手史料）。刘向误记为"与孙膑议兵赵孝成王前"——孙膑活动的年代早于此近百年，这是刘向叙录的明显错误（详见三·分歧 4）。 |
| **同行对话** | 《议兵》末段有"李斯问孙卿子"：秦"四世有胜，兵强海内，威行诸侯，非以仁义为之也，以便从事而已"。荀子答："非女所知也。女所谓便者，不便之便也；吾所谓仁义者，大便之便也。"——**这是全书中最锋利的一次师生交锋**，且是荀子少数直接回应"秦为什么赢"的地方。 |
| **后世评价** | 传统上视为儒家"义兵"论的代表文本。现代研究多指出其军事判断有现实感（对各国兵制的分级评价相当内行），但"仁义必胜"的结论缺乏可操作的中层机制。余治平提醒：《议兵》中"李斯问"一段是否为后人窜入"尚有存疑而不能确定"，因为只记"李斯问"而未与入秦事相连。 |

### D10　春申君死而废，家居兰陵著书

| 项 | 内容 |
|---|---|
| **做了什么** | 前 238 年，楚考烈王死，李园伏死士刺杀春申君于棘门，全家被诛。荀子作为春申君所任之官，**被免废**。他没有离开兰陵，就在当地安家，著书数万言，死后葬于兰陵。 |
| **处境约束** | 此时荀子已七八十岁（按"年十五游齐"说）或近百岁（按"年五十"说）。政治靠山彻底消失，楚国政局血腥。**再出仕已无可能，也无意义**。 |
| **史料依据** | 《史记》"春申君死而荀卿废，因家兰陵"；刘向同，并加"孙卿卒不用于世，老于兰陵"（一手史料）。春申君被刺事见《史记·春申君列传》（一手史料）。 |
| **"废"字的分量** | 不是"退休"，是"被废"。司马迁用一个"废"字，与前面"三为祭酒"的"为"形成落差。 |
| **著书的动因** | 刘向/司马迁给的理由是**愤**："荀卿嫉浊世之政，亡国乱君相属，不遂大道而营于巫祝，信禨祥，鄙儒小拘，如庄周等又猾稽乱俗，于是推儒、墨、道德之行事兴坏，序列著数万言而卒。"即：**因为看不下去，所以写下来**。这是一个"政治失败→文本生产"的标准转化，也是先秦诸子晚年的共同模式。 |
| **后世评价** | 汪中由此立论："六艺之传赖以不绝者，荀卿也。"——把"废"读成"文化上的补偿性胜利"。这个读法很有力量，但也要看到它的代价：**荀子本人想要的是治国，不是传经**。把他追认为"传经之儒"，某种意义上是后人为他的失败找的意义。 |

### D11　授徒：李斯、韩非、浮丘伯、张苍

| 项 | 内容 |
|---|---|
| **做了什么** | 在齐、楚期间授徒。可考弟子：李斯（《史记》孟荀列传明载"李斯尝为弟子，已而相秦"）、韩非（《史记·老子韩非列传》"与李斯俱事荀卿，斯自以为不如非"）、浮丘伯（刘向："又浮丘伯，皆受业，为名儒"）、张苍（SEP 列出；《史记》张苍传称其"好书律历"，汉初为丞相）。 |
| **处境约束** | 稷下与兰陵都是"师徒—游士"网络的一部分。授徒既是学术活动，也是**政治投资**：弟子的出路就是学派的出路。 |
| **史料依据** | 《史记》两传（一手）；刘向《书录》（一手）；SEP 弟子名单。 |
| **评价与争议** | 这是荀子一生中**后果最重大的决策，也是他最不能控制的**。李斯相秦、韩非著书，都成了"荀学助秦"的证据链。但要注意：①《荀子》书中**没有一处**称赞或推荐韩非、李斯；②《议兵》里荀子当面驳李斯；③《非十二子》批尽诸子，未提韩非（韩非或太年轻）。所以"荀子教出了法家"是事实，"荀子教的是法家"不是事实。 |
| **一条反向证据** | 《荀子·议兵》记荀子对李斯说"女所谓便者，不便之便也"，语气是训斥而非赞赏。这说明**师生关系并不和睦**，至少思想上已经分裂（余治平亦持此看法，并疑该段或为窜入）。 |

### D12　（隐含决策）不仕秦、不事新主

| 项 | 内容 |
|---|---|
| **做了什么** | **什么也没做。** 前 238 年后至去世（约前 235 或更晚），他留在兰陵，没有像很多战国士人那样转投秦国或他国。 |
| **处境约束** | 秦的统一进程（前 230 灭韩、前 225 灭魏、前 223 灭楚）正在他晚年发生。以他的名声，若愿入秦，李斯在位，不会没有位置。 |
| **史料依据** | **无直接记载**。这是从"春申君死而废，因家兰陵……而卒"这一句推出来的**沉默证据**。可信度：推论，非史料。 |
| **评价** | 不宜过度浪漫化。更可能的解释是年龄与健康，而非政治气节。但"没有去"这个事实本身，与他一贯的"不合则去、不降志"模式一致，可以作为人格线索保留，**但不要当作史料陈述**。 |

## 三、史料分歧清单

### 分歧 1　"年五十"还是"年十五"始来游学（最著名的一桩）

| 说法 | 代表学者 | 依据 |
|---|---|---|
| **A. 年五十** | 颜之推、唐仲友（部分）、汪中、刘师培、胡适、蒋伯潜、熊公哲、梁启雄、罗根泽、陈登元、龙宇纯、廖名春、梁涛、林桂榛 | ①《史记》本传作"年五十"；②刘向《叙录》作"年五十"；③颜之推《家训·勉学》所见《史记》古本已作"五十"，"未可遽以为讹字"（汪中）；④"始"字含"来迟了"义，若十五岁不必用"始"（胡适）；⑤"游学"可指学术交流而非求学（梁涛）；⑥"有秀才"可解为"才学卓异"而非年少聪颖（廖名春）；⑦汉张苍、唐曹宪皆百有余岁，"何独于卿而疑之"（汪中）。 |
| **B. 年十五** | 晁公武、朱熹、王应麟、吴师道、卢文弨、顾广圻、《四库提要》、黄式三、黄以周、胡元仪、梁启超、钱穆、游国恩、刘蔚华、郭志坤 | ①应劭《风俗通义·穷通》："是时孙卿有秀才，年十五，始来游学"——唯一的"十五"记载；②晁公武《郡斋读书志》直指《史记》"五十"为"十五"之讹；③若五十游齐于威宣之世，至春申君死（前 238）则一百三十七岁，不可能（唐仲友算）；④"游学"是"从学于稷下诸先生而不名一师"，非五十岁学成后之事（钱穆）；⑤"有秀才"是"年少英俊之称"（钱穆）；⑥"始来游学"是相对于"其后最为老师"而言，谓其初来尚幼（钱穆）。 |
| **钱穆的额外论据（独特）** | — | 他不用"春申君死"作坐标，而用《韩非子·难三》"燕王哙贤子之而非孙卿"：燕王哙让国在前 316，时荀子"至少亦当二十四五岁"，上推则"荀卿之生当在周显王三十年前"（即前 339 以前）。结论："荀卿盖亦寿者也。" |
| **目前的处理方式** | — | 无共识。中国社会科学网综述的评断是："到目前为止，似乎仍然没有一种说法能够获得多数人的认可和信服……其中最足称道者，恐怕还是非钱穆莫属。"（**这是一家之言，非定论**） |

来源：中国社会科学网《荀子行历述考及补正》，https://www.cssn.cn/zx/zgzx/202210/t20221027_5554859.shtml （**学术研究，诸家引文与页码齐全，是这一争议最好的单篇综述**）；汪中、钱穆、胡适原文均转引自此文。另见国家图书馆出版社《子藏·儒家部·荀子卷》前言，https://www.nlcpress.com/ProductView.aspx?Id=11206 （一手版本信息 + 两说并列）。

**读这一争议的方法论收获**：双方都用"文本细读"，都讲得通。差别在于**谁承担举证责任**。主"五十"者说"没有硬证据不能改字"；主"十五"者说"不改字就得出荒谬的年寿"。这是**文本保守主义 vs 融贯性优先**的冲突，不是谁读书不细。

### 分歧 3　遭谗去齐 vs 谏不听去齐

| 说法 | 依据 |
|---|---|
| A. 齐人进谗 | 《史记》本传、《孙卿书录》 |
| B. 谏齐王不听，诸儒散去 | 《盐铁论·论儒》："（湣王）矜功不休……诸儒谏不从，各分散，慎到、捷子亡去，田骈如薛，而孙卿适楚" |
| **评断** | 两说不必然冲突，可视为先后环节。但《盐铁论》是论辩文本，其"儒者见弃"的叙事有修辞目的，作为史实需谨慎。 |

### 分歧 4　"与孙膑议兵"还是"与临武君议兵"

| 说法 | 依据 |
|---|---|
| A. 孙膑 | 刘向《书录》："至赵，与孙膑议兵赵孝成王前。孙膑为变诈之兵，孙卿以王兵难之，不能对也。" |
| B. 临武君 | 《荀子·议兵》原文："临武君与孙卿子议兵于赵孝成王前。" |
| **评断** | **B 为是**。孙膑主要活动于齐威王时期（桂陵前 353、马陵前 341），距赵孝成王（前 265 即位）近百年，不可能同席。刘向此处明显致误（可能因"孙"字而混）。胡适正是抓住这一条攻击刘向《叙录》整体不可信（见 04 文件二·1）。 |
| **连带影响** | 这条错误使"刘向叙录的年代信息是否可信"成为问题，进而影响"年五十"说的可靠性评估。**一个错字，牵动整条证据链**。 |

### 分歧 5　韩非、李斯是否真为门人

| 说法 | 依据 |
|---|---|
| A. 是 | 《史记·老子韩非列传》："（韩非）与李斯俱事荀卿，斯自以为不如非。"《史记·孟子荀卿列传》："李斯尝为弟子，已而相秦。"刘向《书录》："李斯尝为弟子……及韩非号韩子，又浮丘伯，皆受业，为名儒。" |
| B. 可疑 | ①《荀子》全书**未提韩非**；②《议兵》有"李斯问"，但李斯入秦（前 247 前后）时荀子年事已高且在兰陵，师徒能否相见存疑；③余治平指出《议兵》李斯问一段"是否为后人杜撰，或者，法家学派文本的有意无意串入，尚有存疑而不能确定"；④钱穆考韩非与李斯同学，据二人年岁相当推算韩非寿"四五十之间"，但陈奇猷反对（同学不必同年，孔门曾参、仲由相差三十七岁）。 |
| **评断** | "李斯受业"证据较硬（两处独立记载）；"韩非受业"只有《老子韩非列传》一句，且与《荀子》全书无韩非之名形成张力。多数学者接受传统说法，但**这是一条应当标注不确定性的记载**。 |

### 分歧 6　兰陵令的时间与次数

| 说法 | 依据 |
|---|---|
| A. 两次，均在春申君相楚期间（前 262—前 238） | 刘向《书录》明确写"以为兰陵令"—"谢之"—"复为兰陵令" |
| B. 一次，在湣王末年那次离齐适楚（前 285 前后），时荀子 55、56 岁 | 中国社会科学网文，理由是"年八十为兰陵令"于理不通 |
| **评断** | A 有明确文本支持（"复为"二字），B 是对"八十为令"的合理性反驳。二者可调和为：**早年一次（短期）+ 春申君时一次**，但无直接证据。标为**存疑**。 |

### 分歧 7　是否曾游燕（非齐、楚、赵、秦之外的第五国）

| 说法 | 依据 |
|---|---|
| A. 曾游燕，且谏阻燕王哙让国 | 《韩非子·难三》："燕王哙贤子之而非孙卿，故身死为僇。"汪中据此谓"荀子游燕，在游齐之前，事仅见此"。钱穆采信，并以此定生年。 |

### 分歧 8　入秦的年代

| 说法 | 依据 |
|---|---|
| 前 266 年 | 国图出版社前言："亦尝于公元前二六六年入秦，与秦昭王、范睢论大儒之效及强国之法；于公元前二六五年至公元前二四五年间返赵，与临武君议兵于赵孝成王之前" |

## 四、决策模式小结（供"用荀子视角"时调用）

从上述十一项可抽出四条反复出现的行为模式。**这些是归纳，不是荀子自述**：

1. **不合则去，不抗争。** 遭谗去齐、被谢去赵、春申君死而废——三次都是"走"，没有一次是"斗"。没有吴起式的以死相搏，也没有孔子式的"迟迟吾行"。
   → 对应思想：他把秩序寄托在**制度与文本**上，而非个人意气。

2. **用文字施压，不用关系施压。** 唯一一次成功反击（D7）是"遗书 + 作赋"。
   → 对应思想：正名、辩说、"以仁心说，以学心听，以公心辩"。

3. **说真话，但不为说真话付超额代价。** 对秦说"其殆无儒邪"，对赵说"仁义之兵"，凡肯听的君主就把该说的说完；说完不被用就走。
   → 这是**游士的理性**：言论空间以"随时可离开"为担保。

4. **把失败转化为文本。** 晚年"嫉浊世之政"而著书数万言。这是被动选择，也是他影响后世两千年的**唯一实际通道**。
   → 反讽：他一生想做的（治国）失败了，不想做的（传经）成功了。

**一个必须保留的疑虑**：以上四条模式，很大程度上是从"结果"逆推"意图"。史料只记录了他做了什么，没记录他为什么。任何"荀子的决策逻辑"叙述，都应当带着这个方法论警告。
