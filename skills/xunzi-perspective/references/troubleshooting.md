# 故障排查：症状 → 原因 → 动作

按症状查，不要按猜测查。每一条都给了可以当场验证的动作。

## A. 装了但没反应

| 症状 | 最可能的原因 | 动作 |
|---|---|---|
| 说「用荀子的视角」没进入角色 | 会话在安装前就已开始，客户端只在启动时扫描 skills | **新开一个任务**再试。这是最常见的一条，先排除它 |
| 同上，且新开任务也没反应 | 目录层级错了：必须是 `<skills根>/xunzi-perspective/SKILL.md`，不能是 `<skills根>/xunzi-perspective/xunzi-perspective/SKILL.md` | `ls <skills根>/*/SKILL.md` 看路径深度 |
| 同上，路径也对 | frontmatter 被破坏（BOM、缩进、`---` 只有两横） | `head -5 SKILL.md` 应看到 `---` / `name: xunzi-perspective` / `---` |
| Codex 里看不到 | 装到了旧布局 `~/.codex/skills` 但当前版本读 `~/.agents/skills`（或反之） | 两个目录都放一份，或用安装器：`python scripts/install_codex.py`（它会自动判断该往哪装） |
| DeepSeek Harness 里看不到 | 只装了普通网页版 DeepSeek；网页对话**没有**本地 skill 加载能力 | 需按教程安装 dsh 与 `dsh-xunzi-perspective` 插件 |

## B. 进入了角色但不像荀子

症状：结论放在最后、中间是三条并列建议、结尾「综上所述」「希望对你有所帮助」。

| 原因 | 动作 |
|---|---|
| 模型没读到 SKILL.md 的「回答工作流」 | 在提问里加一句：「按四段式：断语 / 分档 / 证据 / 反问收束」 |
| 问法太"百科"（「荀子的十个观点」） | 换成判断类问法：「以荀卿论之：X 该不该做？」 |
| 长对话后掉了人设 | 说「重新按 skill 规则来」，或新开会话。SKILL.md 的「跑偏自检」就是为这个写的 |

**验收标准**（照此自查，不要凭感觉）：

1. 第一句是不是判断？
2. 有没有给出**轴**（凭什么是它立足的）？只给三档不给轴 = 列清单，不算分档。
3. 三档能不能互换顺序？能换 = 没轴，重做。
4. 结尾是引经 / 命名 / 反问之一？
5. 有没有出现「可能」「也许」「在一定程度上」这类缓和词？出现就是跑偏（SKILL.md 明令删除）。

## C. 引文对不上

| 症状 | 原因 | 动作 |
|---|---|---|
| 它引了某句原文，你翻书找不到 | 见 SKILL.md 的「未取到原文的句子不许当确凿证据」三条 | 该条已点名的句子（如《劝学》「学至乎礼而止」）**只能给立场，不能给原话**。要原话改引已核的句子 |
| 它把「人定胜天」当成荀子的话 | 「人定胜天」是 2010 年编者的按语，非原文 | 已经在 SKILL.md 里做成硬约束；若仍出现，指出「这是编者按语」并要它改引「制天命而用之」+「唯圣人为不求知天」成对 |
| 它说荀子是「朴素唯物主义者」 | 这是注释本的现代范畴，不是战国语汇 | 同上，要求区分「原文 / 编者按 / 现代解读」三层 |

## D. 涉及现代事实时胡说

角色扮演不替代检索。**先退出角色**（说「退出」），再问事实；或明确要求：「先查资料，再以荀子视角评」。

SKILL.md 的 Agentic Protocol 已经要求「涉事实先研究」，但部分客户端不开放检索工具，此时它只能凭训练语料说话——这是环境限制，不是 skill 缺陷。

## E. 渲染脚本报错

| 报错 | 原因 | 动作 |
|---|---|---|
| `找不到底本 PDF` | 底本受版权保护，不随包分发 | 三选一：放到 `<skill>/references/sources/books/`；设 `XUNZI_PDF`；加 `--pdf` |
| `缺少 pypdfium2` | 当前 Python 没装 | `python -m pip install pypdfium2`，或用带该库的解释器 |
| `跳过越界页 pdf N` | 页码算错了 | 换算公式 `pdf = 书页 + 13`；用 `--list-chapters` 对一遍 |
| 中文路径报错 | Windows 控制台编码 | 用引号包住路径，或在 UTF-8 终端里运行 |

## F. 装坏了想回滚

安装器在覆盖前会自动备份到 `<skills根>/xunzi-perspective.backup-<时间戳>`。

```bash
# 列出备份
ls <skills根>/ | grep xunzi-perspective.backup

# 回滚（先删当前，再改名回来）
rm -rf <skills根>/xunzi-perspective
mv <skills根>/xunzi-perspective.backup-<时间戳> <skills根>/xunzi-perspective
```

彻底卸载：删掉 `<skills根>/xunzi-perspective` 即可。本 skill 不在系统任何其它位置写入文件。
